# Weather Digest 🌤

Консольная утилита на Node.js для получения прогноза погоды по названию города через открытый API [Open-Meteo](https://open-meteo.com/). Умеет обрабатывать несколько городов сразу, кэшировать отчёты и сохранять их в JSON-файлы.

## Требования

- Node.js **20 или выше**
- npm 10+

## Установка

```bash
git clone https://github.com/Valya03/weather-digest.git
cd weather-digest
npm install
```

## Переменные окружения

Скопируйте `.env.example` в `.env` (по желанию, все параметры имеют значения по умолчанию):

| Переменная           | По умолчанию                                     | Описание                     |
| -------------------- | ------------------------------------------------ | ---------------------------- |
| `GEOCODING_BASE_URL` | `https://geocoding-api.open-meteo.com/v1/search` | URL API геокодинга           |
| `FORECAST_BASE_URL`  | `https://api.open-meteo.com/v1/forecast`         | URL API прогноза             |
| `REQUEST_TIMEOUT`    | `5000`                                           | Таймаут запроса в мс         |
| `REPORTS_DIR`        | `reports`                                        | Папка для сохранения отчётов |
| `TEMPERATURE_UNIT`   | `celsius`                                        | Единицы температуры          |

## Запуск

```bash
node src/index.js --city "Москва" --days 3
```

### Параметры

| Параметр     | Обязательный | По умолчанию | Описание                                                           |
| ------------ | ------------ | ------------ | ------------------------------------------------------------------ |
| `--city`     | да           | —            | Название города. Можно несколько через запятую: `"Москва, Казань"` |
| `--days`     | нет          | `3`          | Количество дней прогноза (1–7)                                     |
| `--no-cache` | нет          | —            | Форсирует сетевой запрос, игнорируя кэш                            |

### Пример вывода

```

```

## Обрабатываемые ошибки

| Ситуация          | Сообщение                                   |
| ----------------- | ------------------------------------------- |
| Нет `--city`      | «параметр --city обязателен»                |
| Неверный `--days` | «--days должен быть целым числом от 1 до 7» |
| Город не найден   | «Город "X" не найден»                       |
| Ответ 4xx         | «Ошибка клиента (400)»                      |
| Ответ 5xx         | «Ошибка сервера (500)»                      |
| Нет сети          | «Нет соединения с сетью»                    |
| Таймаут           | «Превышено время ожидания ответа»           |
| Некорректный JSON | Перехватывается автоматически               |

## Коды завершения

- `0` — успех
- `1` — ошибка

## Кэширование

Если отчёт по городу за текущую дату уже есть в `reports/`, данные берутся из файла **без сетевого запроса**. Чтобы принудительно обновить данные, используйте флаг `--no-cache`.
